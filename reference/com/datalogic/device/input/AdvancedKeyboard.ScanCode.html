Class Overview

Collection of scan code constants used to configure and identify key mappings for the Datalogic logo overlay.
Each constant represents a hardware scan code associated with a keyboard key, function key, navigation key, trigger or device-specific action supported by Datalogic devices.
The values are aligned with Linux input subsystem scan codes, extended with Datalogic-specific proprietary codes.
